# Product: Academix

Desktop academic management system for educational institutions.

## Purpose

Manage students, courses, groups, attendance, payments, accounting, and user administration from a single desktop application.

## Target Users

Academic administrators and staff at educational institutions (academies, schools, training centers).

## Core Domains

- **Auth**: Login, session management, role-based access
- **Students**: Enrollment, student records
- **Courses**: Course catalog and configuration
- **Groups**: Class/group management
- **Attendance**: Tracking student attendance
- **Payments**: Payment processing and tracking
- **Accounting**: Financial records and invoicing
- **Users**: Staff and admin user management
- **Dashboard**: Overview and reporting (charts, PDF exports)

## Platform

Desktop-only (Windows, macOS, Linux) via Tauri. Not a web app.
