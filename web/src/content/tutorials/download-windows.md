## Requisitos

- Windows 10 o superior
- Arquitectura x64 o arm64
- WebView2 (incluido en Windows 11, instalado automáticamente en Windows 10)

## Pasos de instalación

1. Visita la [página de descargas](/downloads) y haz clic en el botón de descarga para Windows.
2. Ejecuta el archivo `.msi` descargado.
3. Sigue las instrucciones del instalador.
4. Una vez instalado, abre Academix desde el menú de inicio.

## Primer inicio

Al abrir la aplicación por primera vez, se te pedirá crear una cuenta de administrador. Ingresa tu email y una contraseña segura para comenzar.
